# AI Prompt Studio Pro

A lightweight Cloudflare Worker website with no build step.

## Cloudflare settings
- Root directory: `/`
- Build command: leave blank / None
- Deploy command: `npx wrangler deploy`
- Production branch: `main`

The app is a client-side prompt studio: Video, Image, Story and Social modes, with style/tool/format/niche controls and a copy button.
